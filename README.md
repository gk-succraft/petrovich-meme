# Stickers — Custom stickers for Google Chat

Chrome extension that adds a sticker panel to Google Chat.  
Stickers are loaded directly from a GitHub repository — just upload an image and it's instantly available.

---

## 📦 Installation (Manual only)

1. **Clone the extension repository**
2. Open Chrome and go to:  
   `chrome://extensions/`
3. Enable **Developer mode** (toggle in the top right corner)
4. Click **"Load unpacked"**
5. Select the extension folder
6. Done!

---

## 🎮 How to use

### Basic workflow

| Step | Action |
|------|--------|
| 1 | Open **Google Chat** (mail.google.com or chat.google.com) |
| 2 | **Click inside the chat input box** (this is important!) |
| 3 | Press **`Ctrl + Shift + S`** (or `Cmd + Shift + S` on Mac) |
| 4 | Click any sticker in the panel |
| 5 | Press **`Ctrl + V`** to paste |
| 6 | Press **Enter** — sticker sent! 🚀 |
